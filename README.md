# Toruok Space

A human opportunity engine for physical spaces — schools, hotels, libraries, cafés, coworking spaces, and universities.

People discover relevant people, opportunities, resources, and activities within the spaces they're physically present in. Space operators configure and author what their environment offers; participants get one persistent identity that adapts as they move between spaces.

## Stack

Next.js 16, TypeScript, Supabase (Postgres + RLS), Tailwind CSS.

## Development

\`\`\`bash
npm install
npm run dev
\`\`\`

## Schema

See \`schema_v2.sql\` for the current database schema (Organizations, Spaces, Zones, Profiles, Presence, Connections, Opportunities, Resources, Activities).
